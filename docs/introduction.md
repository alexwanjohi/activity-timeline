## Introduction

@zeus activity-timeline adds timeline UI components for Filament Infolists, including support for Spatie Activitylog integrations.

**[Github](https://github.com/lara-zeus/activity-timeline) · [Packagist](https://packagist.org/packages/lara-zeus/activity-timeline) · [Discord](https://discord.com/channels/883083792112300104)**

## Features

- Add timelines to custom pages or Infolist entries
- Works with both `->state([])` and `->record()`
- Optional integration with `spatie/laravel-activitylog`
- Configurable empty states and display behavior
